# Loyihani Ishga Tushirish Qo'llanmasi

Loyiha to'liq ishlashi uchun quyidagi qadamlarni bajaring.

## 1. Kutubxonalarni O'rnatish
Terminalda quyidagi buyruqni bosing. Bu loyiha uchun kerakli barcha fayllarni (internetdan) yuklab oladi.

```bash
npm install
```

## 2. Loyihani Ishga Tushirish
O'rnatish tugagandan so'ng, loyihani "jonli server"da ochish uchun:

```bash
npm run dev
```

Sizga quyidagicha yozuv chiqishi kerak:
`➜  Local:   http://localhost:5173/`

Shu manzilni brauzerda oching va loyiha ishlaydi!
