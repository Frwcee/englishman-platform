# YAPPENG Registration Platform

A modern, mobile-first registration platform for YAPPENG English Speaking School.

## 🚀 Getting Started

This project was built with React + Vite.

### 1. Install Dependencies
Run the following command in your terminal:
```bash
npm install
```

### 2. Start the App
Start the development server:
```bash
npm run dev
```

Then open the link shown (usually `http://localhost:5173`) on your phone or in mobile view in Chrome DevTools to see the intended design!

## 📱 Features
- **Mobile-First Design**: Optimized for phone screens.
- **Mascot**: A friendly floating mouse companion.
- **Step-by-Step Registration**: Duolingo-style form wizard.
- **Grammar Placement Test**: 50 questions from A1 to C2.
- **Auto-Grading**: Instant level calculation and course recommendation.

## 🛠️ Tech Stack
- React
- Vite
- Framer Motion (Animations)
- Vanilla CSS Variables (Theming)
