# YAPPENG Design Specification

## Core Identity
**Goal:** Professional, clean, and trustworthy online platform for English speaking courses.
**Feel:** Official, Modern, Structured, Reliable, yet friendly and human. NOT boring or academic.

## 1. Visual Style
- **Layout:** Minimalistic, clean.
- **Reference:** Subtle Duolingo influence (softness only, NO playfulness).
- **Shapes:** Rounded corners (light, not cartoonish).
- **Depth:** Very light shadows or no shadows.
- **Motion:** Calm animations only where necessary.
- **Restrictions:** No bright illustrations, no childish graphics.

## 2. Color Palette
- **Primary:** Deep green or muted green.
- **Secondary:** White / off-white backgrounds.
- **Accent:** Soft gray, muted blue (for links & info).
- **Prohibited:** No neon, no high saturation colors.

## 3. Typography
- **Headings:** Modern sans-serif, confident and neutral.
- **Body:** Simple, readable, professional.
- **Hierarchy:** Strong headings, calm body text.
- **Restrictions:** No emojis inside main content (allowed only in very small UI hints if needed).

## 4. Layout Structure

### Landing Page
- **Headline:** "English Speaking Programs by YAPPENG"
- **Sub-headline:** "Practical. Speaking-Centered. Result-Driven."
- **Intro:** Short textual introduction.
- **Primary CTA:** "Register for the Course"
- **Secondary CTA:** "View Program Details"
- **Buttons:** Rectangular with slightly rounded corners. No bounce animations. Smooth fade/color change on hover.

### Course Information
- Grid or vertical blocks.
- Clean information cards.
- Minimal professional icons.
- Focus on clarity.

### Program Structure
- Step-based layout (1 → 2 → 3 → 4).
- Title + short explanation line per step.
- No distracting scrolling animations.

## 5. Floating Assistant (Replacements Mascot)
- **Concept:** Support, not entertainment.
- **Visuals:** Simple circle or minimal icon. Muted green or gray.
- **Position:** Bottom-right corner.
- **Behavior:** Appears only when user pauses or scrolls down.
- **Interaction:** Opens small help tooltip (e.g., "Need help with registration?", "Questions about the course?").
- **Restrictions:** No facial expressions, no bouncing, no playful motion.

## 6. Registration & Forms
- Layout: Clean, formal.
- Structure: Multiple steps separated.
- Indicators: "Step 1 of 3".
- Inputs: Full width, clear labels above inputs.
- Validation: Neutral and polite messages.

## 7. Grammar Test Design
- Interface: Distraction-free, white background.
- Layout: Question centered, answer choices in clean bordered boxes.
- Progress: "Question 12 / 50".
- Motion: Subtle transitions only.
- Helper: Floating assistant HIDDEN during test.

## 8. Result & Confirmation Screen
- Content: Clean result summary, grammar level clearly displayed.
- Actions: 
    - "Proceed to Payment"
    - "Contact Admin (Telegram)"

## 9. Motion & Interaction rules
- Examples: Subtle fades, transitions.
- Prohibited: Bouncing, playful sounds.
- Goal: Clarity and confidence.

## 10. Brand Impression
- Trust
- Seriousness
- Structure
- Professionalism
